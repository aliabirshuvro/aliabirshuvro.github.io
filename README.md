# Ali Abir Shuvro — personal website

Static site for GitHub Pages. No build step.

    index.html                  the whole site (edit text here)
    assets/profile.png          profile photo
    files/Ali_Abir_Shuvro_CV.pdf  CV linked from the page

## Deploy
1. Create a public repo named exactly `aliabirshuvro.github.io`.
2. Upload these files to the repo root (keep the folders).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute, the site is live at https://aliabirshuvro.github.io

## Before publishing
- To update the CV, replace files/Ali_Abir_Shuvro_CV.pdf with a file of the same name.
